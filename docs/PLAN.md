# 모의주식 — 기획 정리

가상 자금 1,000만 원으로 주식을 사고파는 모의 투자 웹 앱. 보유 종목·잔고·수익률은 저장하지 않고 거래 기록에서 SQL로 계산한다.

- 프론트엔드: React (Vite) — `paper-trading/`
- 백엔드: Node.js + Express — `server/` (예정)
- 데이터베이스: MySQL 8.0.16 이상, SQL 직접 작성 (mysql2)
- 언어: JavaScript (TypeScript 사용 안 함)

---

## 1. 화면 구성

모든 화면(회원가입 제외)은 상단에 같은 메뉴 바를 둔다.
메뉴 바: 로고 `모의주식` · 마켓 · 포트폴리오 · 거래 내역 · 랭킹 · 관리자 · 보유 현금 · 닉네임

### 1-1. 회원가입 · 계좌 개설

- 왼쪽: 검정 소개 영역 — 서비스 이름, "가상 자금 1,000만 원으로 투자를 연습해 보세요", 이용 순서 3단계, "실제 돈과 시세를 쓰지 않는 연습용" 안내
- 오른쪽: 흰색 폼 — 닉네임, 이메일, 비밀번호, 비밀번호 확인, 계좌 이름(기본값 "기본 계좌"), 초기 입금액 10,000,000원 표시, "가입하고 시작하기" 버튼
- 입력 검사: 이메일 형식, 비밀번호 일치
- API: `POST /api/signup` — 사용자 INSERT + 계좌 생성 + 초기 자금 입금을 한 트랜잭션으로

### 1-2. 마켓 (종목 목록)

- 제목, 시뮬레이션 날짜, 종목 검색창
- 요약 카드 4개: 상승 종목 수, 하락 종목 수, 보합 종목 수, 내 관심 종목 수
- 섹터 필터 칩: 전체 · 전자 · 바이오 · 에너지 · 게임 · 운송 · 식품 · 유통 · 금융
- 종목 표: 관심(별) · 종목명/코드 · 섹터 · 현재가 · 전일 대비 · 등락률 · 주문 버튼
- 종목명이나 주문 버튼을 누르면 종목 상세로 이동
- API: `GET /api/stocks`, `POST/DELETE /api/watchlist/:stockId`

### 1-3. 종목 상세 · 주문

- 상단: 종목명, 코드, 섹터, 현재가, 전일 대비(금액·%), 기준일과 전일 종가
- 왼쪽: 종가 추이 차트, 일별 시세 표(날짜 · 시가 · 고가 · 저가 · 종가 · 전일 대비)
- 오른쪽: 주문 패널
  - 매수/매도 전환
  - 주문 유형: 시장가 (지정가는 확장 기능 자리만)
  - 수량 입력, −/+ 버튼, 최대 버튼
  - 요약: 주문 단가, 주문 가능 금액(매수) 또는 매도 가능 수량(매도), 최대 주문 수량, 예상 주문 금액
  - 잔고·보유 수량 초과 시 경고 문구와 버튼 비활성화
  - 주문 완료 메시지
- 오른쪽 아래: 내 보유 현황 — 보유 수량, 평균 매입가, 평가 금액, 평가 손익
- API: `GET /api/stocks/:id`, `GET /api/stocks/:id/prices`, `POST /api/orders`

### 1-4. 내 포트폴리오

- 검정 요약 박스: 총 자산, 총 수익(금액·%), 보유 현금, 주식 평가 금액, 평가 손익, 실현 손익
- 자산 구성 막대: 주식 vs 현금 비율
- 섹터별 투자 비중 막대 + 범례
- 보유 종목 표: 종목 · 보유 수량 · 평균 매입가 · 현재가 · 매입 금액 · 평가 금액 · 평가 손익 · 수익률 · 주문 버튼 (평가 금액 큰 순)
- API: `GET /api/portfolio`

### 1-5. 거래 내역

- 요약 카드 4개: 체결 건수, 매수/매도 건수, 실현 손익, 현재 잔고
- 구분 필터: 전체 · 매수 · 매도 · 입금
- 표 (최신순): 일시 · 구분 배지 · 종목 · 수량 · 체결가 · 현금 증감 · 거래 후 잔고 · 상태
- API: `GET /api/history?type=`

### 1-6. 수익률 랭킹

- 제목, 참가자 수, 내 순위 박스
- 1~3위 카드: 순위 메달, 닉네임, 수익률, 총 자산
- 전체 순위 표: 순위 · 닉네임(내 행은 "나" 배지와 배경색) · 총 자산 · 수익 · 수익률 · 보유 종목 수
- 수익률이 같으면 같은 순위
- API: `GET /api/ranking`

### 1-7. 관리자 · 가격 입력

- 시세 입력 폼: 종목 선택, 거래일, 시가 · 고가 · 저가 · 종가
- 저장 전 확인 목록: 가격 > 0, 고가 ≥ 시가·종가, 저가 ≤ 시가·종가, 같은 종목·거래일 시세 없음
- 하나라도 통과하지 못하면 저장 버튼 비활성화
- 오른쪽: 시뮬레이션 날짜, "다음 거래일로" 버튼, 오늘 입력 현황(종목별 종가)
- API: `POST /api/admin/prices`, `POST /api/admin/next-day`

## 2. 기능 목록

### 2-1. 기본 기능 (최소 완성본)

1. 회원가입과 계좌 개설, 초기 자금 10,000,000원 지급
2. 종목 목록과 현재가·전일 대비·등락률 조회
3. 시장가 매수·매도 (현재가로 즉시 체결)
4. 포트폴리오: 보유 종목, 평균 매입가, 평가 금액, 수익률
5. 주문·체결·입금 내역 조회
6. 관리자 가격 입력

### 2-2. 확장 기능

1. 1분마다 가격 자동 생성 (아래 2-4)
2. 관심 종목, 종목별 가격 차트
3. 수익률 랭킹
4. 섹터별 투자 비중, 일별 자산 추이
5. 기간 최고가·최저가 표시
6. 지정가 주문
7. 타임머신 모드 (과거 가격 데이터를 하루씩 넘기며 투자)

### 2-3. 하지 않는 것

공매도, 신용거래, 배당, 세금, 수수료(처음엔 제외), 사용자 간 호가 매칭

### 2-4. 가격 자동 생성 규칙

- 실제 1분 = 시뮬레이션 1거래일. 1분마다 모든 종목의 다음 거래일 시세 한 줄을 만든다.
- 변동률 = −변동성 ~ +변동성 사이 난수 + 평균 회귀 값
  - 변동성: 종목별 값 (기본 ±3%, 1분 주기라 ±1~2%도 고려)
  - 평균 회귀: `0.05 × (기준가 − 전일 종가) ÷ 기준가` — 기준가에서 멀어질수록 반대로 당김
- 새 종가 = 전일 종가 × (1 + 변동률), 10원 단위로 반올림
- 최저·최고 한계가를 넘으면 한계값으로 자른다 (예: 기준가의 30%~300%)
- 시가는 전일 종가 근처, 고가 = max(시가, 종가) + α, 저가 = min(시가, 종가) − α → 고가·저가 규칙 항상 통과
- 모든 종목을 한 트랜잭션으로 저장, 실패하면 전체 롤백
- 가격 테이블 기본 키 (종목ID, 거래일)로 중복 생성 차단
- 서버를 다시 켤 때 마지막 생성 시각을 확인해 밀린 만큼 한 번에 생성
- 페이지를 열 때마다 난수를 돌리지 않는다 (생성은 서버에서만, 저장된 값만 보여 줌)
- 종목 테이블에 추가할 컬럼: 기준가, 변동성, 최저 한계가, 최고 한계가 (CHECK: 0 < 최저 < 기준가 < 최고)

### 2-5. 계산하는 값 (저장하지 않음)

- 등락률 = (오늘 종가 − 전일 종가) ÷ 전일 종가 × 100 — 전일은 그 종목의 바로 이전 행 (`LAG`)
- 기간 최고가·최저가 = 기간 내 `MAX(고가)`, `MIN(저가)`
- 보유 수량 = 매수 체결 합 − 매도 체결 합
- 평균 매입가 = 이동평균법
- 현금 잔고 = 현금 원장 합
- 수익률 = (평가 금액 − 매입 금액) ÷ 매입 금액 × 100
- 총 자산 = 현금 잔고 + 평가 금액, 랭킹 = `RANK()`

### 2-6. 주문 처리 (POST /api/orders)

1. 트랜잭션 시작
2. 계좌 행 잠금 (`SELECT … FOR UPDATE`)
3. 잔고 또는 보유 수량 확인
4. 가능하면 주문 · 체결 · 현금 원장을 함께 기록하고 커밋
5. 불가능하거나 오류면 전체 롤백

### 2-7. 지켜야 할 것

- SQL에는 항상 파라미터 바인딩 (`?`)
- DB 접속 정보는 `.env`에, `.env`는 `.gitignore`에
- React는 DB에 직접 접근하지 않고 API만 호출
- 비밀번호는 해시로 저장
- 금액은 원 단위 정수(INT) — DECIMAL이면 mysql2가 문자열로 돌려주니 `Number()` 변환
- 날짜는 SQL에서 `DATE_FORMAT(…, '%Y-%m-%d')`로 문자열로 내려 줌
- 개발 중 CORS는 Vite 프록시로 해결

- 버튼·입력칸 높이 44px 이상, 모서리 8px

- 주문 버튼: 매수는 빨강, 매도는 파랑, 높이 52px
- 필터 칩: 모서리 999px, 선택되면 검정 배경 + 흰 글자
- 구분 배지: 매수 `#FDECEE`/`#A50E26`, 매도 `#EAF0FD`/`#1D4ED8`, 입금 `#EEF0F3`/`#3F4652`
- 현재 메뉴: `#E9ECF1` 배경 + 굵은 글자

### 3-5. 숫자 표시 규칙

- 금액: `toLocaleString('ko-KR')` → 74,200
- 상승 `▲ 1,700` / `+2.34%`, 하락 `▼ 3,500` / `−2.85%`, 보합은 회색 `0.00%`
- 등락률·수익률은 소수 둘째 자리
- 첫 거래일처럼 전일 값이 없으면 `—`
- 색만으로 구분하지 않고 ▲▼와 +/− 기호를 함께 표시
